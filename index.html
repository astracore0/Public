Dedicated Server Setup

Instructions for Termux, headless Linux VPS, or local hosting.

Quarantine 11 Client-Only Mods: Dedicated servers do not have display screens. Retaining client mods (like Sodium, Xaero's Maps, MouseTweaks) in your server's mods/ folder will crash boot with java.lang.NoClassDefFoundError.
1 Move Client Mods out of Server in Termux / Linux

Run this snippet inside your server directory to quarantine all 11 client-side jars:

bash 
cd **download/mods**
mkdir -p ../client_mods_backup

mv BadOptimizations-2.4.1-1.21.1.jar \
   entityculling-neoforge-1.10.5-mc1.21.1.jar \
   InventoryProfilesNext-neoforge-1.21.1-2.2.5.jar \
   libIPN-neoforge-1.21.1-6.6.3.jar \
   MouseTweaks-neoforge-mc1.21-2.26.1.jar \
   reeses-sodium-options-neoforge-2.2.4+mc1.21.1.jar \
   "Resourcify (1.21.1-neoforge)-1.8.7.jar" \
   shulkerboxtooltip-neoforge-5.1.9+1.21.1.jar \
   sodium-neoforge-0.8.13+mc1.21.1.jar \
   xaerominimap-neoforge-1.21.1-26.5.0.jar \
   xaeroworldmap-neoforge-1.21.1-1.46.0.jar \
   ../client_mods_backup/
2 Tune server.properties

With world-generation mods like Terralith, Tectonic, and Dungeons Arise, set these parameters:

server.properties 
max-tick-time=180000
view-distance=8
simulation-distance=6
network-compression-threshold=256
sync-chunk-writes=false
online-mode=true

Android Mobile (Pojav)

GPU prerequisites, companion bridge, and memory requirements for your phone.

Qualcomm Snapdragon with Adreno GPU Required:
Your phone MUST have a Snapdragon chip with an Adreno 6xx / 7xx series GPU. Phones with MediaTek Dimensity (Mali GPU) will fail to load or produce black screens due to missing desktop OpenGL ES compute shader extensions.
Mandatory Mobile Mod: `sable-bridge`:
The pack includes sable-neoforge-1.21.1-2.0.6.jar. To prevent crashes on mobile touch interfaces, you must install the companion `sable-bridge` mod in your phone's mod folder. Get it from the Downloads tab.
1 Launcher Configurations
  • Renderer: Select Zink (Vulkan) or Turnip + Zink. Do not use standard GL4ES.
  • Java Runtime: Select internal Java 21.
  • RAM Allocation: Set between 4000 MB and 4800 MB (4GB–4.8GB). Avoid exceeding 5GB to prevent Android from killing the background process.
2 Sodium on Mobile Check

If your mobile launcher crashes during splash screen or gives an OpenGL shader initialization error:

  • Delete sodium-neoforge-0.8.13+mc1.21.1.jar and reeses-sodium-options-... from your phone's mod folder.
  • Keep ModernFix and FerriteCore enabled—they are safe on mobile and save over 1 GB of memory.
3 Mobile Mod Folder Destination

Copy your client pack files into your launcher directory:

Pojav path 
/sdcard/Android/data/net.kdt.pojavlaunch/files/.minecraft/mods/

Desktop PC Client (Windows, macOS, Linux)

Optimal configuration for Prism Launcher, Modrinth, or CurseForge.

Runs All 77 Mods Out-of-the-Box: Desktop PC supports all rendering, minimap, and sorting mods. No mod files need to be deleted.
1 JVM Memory & GC Flags

Allocate 6 GB to 8 GB RAM. Paste these flags to minimize Create tick stutter:

Java 21 JVM Arguments 
-Xms6G -Xmx8G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -XX:+AlwaysPreTouch -XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40 -XX:G1ReservePercent=15
2 Keybinding Conflicts to Resolve
  • Backpack (Sophisticated Backpacks): Defaults to B, which clashes with Simple Voice Chat mute. Change Voice Chat mute to M.
  • Minimap Menu (Xaero): Defaults to Y, which overlaps with Waystones list. Change Waystone list to U.

Handhelds & Consoles

Setup for Steam Deck, ROG Ally, and Bedrock console compatibility notes.

🎮 Steam Deck / ROG Ally Setup
  • Install Prism Launcher from the Discover Software Center in Desktop Mode.
  • Controller Input: Add Controlify or MidnightControls (NeoForge 1.21.1) to your client mods for thumbstick and trigger controls.
  • Set Steam Deck TDP to 10W–12W for stable 60 FPS and balanced battery longevity.
🚫 Bedrock Console Crossplay Notice
Bedrock Cannot Join: GeyserMC / Floodgate cannot bridge custom NeoForge entities, blockstates, and kinetic tile data (Create, MineColonies, Apotheosis) to Bedrock consoles (Xbox/PS5/Switch). Players must use the Java edition client.
